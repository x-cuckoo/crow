# Language Rules

Select by the code being changed, not every language present in the repository. For mixed-language changes, read each matching entry. For unlisted languages, use general rules and project conventions.

| Language | Applies to | Writing rules |
| --- | --- | --- |
| JavaScript / TypeScript | JS, TS, JSX, TSX, including module variants | [javascript-typescript.md](javascript-typescript.md) |

To add a language, add its rule file and an index entry. Keep filenames aligned with Validator; put writing guidance here and review criteria there, leaving shared principles in the general rules.
