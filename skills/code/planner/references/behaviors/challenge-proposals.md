# Challenge Proposals

Use this when the user already has a design or implementation idea.

- Treat the proposal as a hypothesis, not the default best design.
- Compare viable alternatives using current code, constraints, and the Planner's decision criteria.
- Propose a materially better design proactively; do not favor a path merely because it is shorter, faster, or more abstract.
- If the proposal has the best total fit, say why.
