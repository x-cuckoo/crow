# Frame

- Identify the target repo, package, or service and the specific mode, stage, and artifacts to change. Shared code or parameters do not expand that scope. When a follow-up names another target, resolve its actual path and owner before carrying work across; a matching name is not sufficient. Carry over the intended outcome, not the previous target's incidental edits.
- State material assumptions; present multiple interpretations instead of choosing silently.
- Preserve constraints, no-touch areas, success criteria, required or forbidden evidence, and explicit domain guarantees.
- Separate the request from what is needed to solve it, then define what will prove completion.
- If the task target, constraints, or success criteria are still unclear, ask the user directly before continuing the plan.
