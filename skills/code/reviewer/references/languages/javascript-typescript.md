# JavaScript and TypeScript

- Check that declaration documentation uses JSDoc (`/** ... */`) immediately before the documented code.
- Check that descriptions and tags add useful information and match the declaration; flag mechanical or redundant tags.
- Check relevant JSDoc types in JavaScript for consistency. In TypeScript, flag types repeated in comments instead of relying on code declarations.
- Accept ordinary comments for local implementation explanations. Do not treat undocumented declarations as violations solely because JSDoc is the required documentation format.
