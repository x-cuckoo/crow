# Language Checks

Select by the code being reviewed, not every language present in the repository. For mixed-language changes, read each matching entry. For unlisted languages, use general checks and project conventions.

| Language | Applies to | Review criteria |
| --- | --- | --- |
| JavaScript / TypeScript | JS, TS, JSX, TSX, including module variants | [javascript-typescript.md](javascript-typescript.md) |

To add a language, add its check file and an index entry. Keep filenames aligned with Executor; put review criteria here rather than copying implementation guidance or general checks.
